# 🧠 AICheck – AI Text Detection

AICheck is an intelligent system for detecting AI-generated text using
a fine-tuned XLM-RoBERTa model.

## Features
- AI vs Human text detection
- Multilingual (EN / FR)
- Real-time analysis
- Interactive Streamlit interface

## Tech Stack
- Python
- Transformers (XLM-RoBERTa)
- Streamlit
- PyTorch

## Deployment
Hosted on Streamlit Community Cloud.
